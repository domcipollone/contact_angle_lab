Pendant settings

Click two points on the image to measure a known distance (e.g., nozzle diameter).

Used only for pendant drop mode. Surface tension γ is computed from the fitted capillary constant: γ = Δρ·g / b, where g is gravitational acceleration and b is the capillary constant from the Young–Laplace fit.

Quick guide

  1. Load a droplet image.
  2. Set the baseline with two clicks along the solid surface. These two base points define the substrate plane and separate the droplet (above) from the solid (below), which sets the reference line for all angles.
  3. Add boundary points (10+ recommended) for circle/ellipse fits.
  4. For manual mode, click four points in order: left contact, right contact, left tangent helper, right tangent helper.
  5. Choose analysis mode and compute.
The baseline is the contact line reference: it defines where the droplet meets the solid and fixes the left/right intersection points for best-fit methods. Manual mode uses the helper points to define a local tangent at each contact point. Circle/ellipse modes fit all boundary points.

Pendant drop SOP

  1. Load a pendant drop image with the full profile visible.
  2. Switch click mode to Boundary points and mark the full profile from apex down both sides (12–30 points recommended).
  3. Enter Δρ (density difference) and the scale in mm/px.
  4. Choose Pendant drop in the analysis tabs and click compute.
Pendant analysis fits the Young–Laplace profile to the boundary points. The fit returns the capillary constant b and apex radius R0; surface tension is γ = Δρ·g / b. Symbols: Δρ density difference, g gravitational acceleration, b capillary constant, R0 apex radius, γ surface tension.
